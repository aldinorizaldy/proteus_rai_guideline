# How to cite

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.XXXXXXX.svg)](https://doi.org/10.5281/zenodo.XXXXXXX)

Every release of this guideline is archived on Zenodo with its own DOI.
Please cite the version you used. To always point to the latest version, use
the *concept DOI* shown on the Zenodo record ("Cite all versions").

## APA (7th edition)

```text
Lastname, F., & Lastname, F. (2026). PROTEUS Responsible AI guideline (Version 0.1) [Guideline]. Helmholtz-Zentrum Dresden-Rossendorf (HZDR). https://doi.org/10.5281/zenodo.XXXXXXX
```

## BibTeX

```bibtex
@techreport{proteus_rai_guideline,
  author      = {Lastname, Firstname and Lastname, Firstname},
  title       = {{PROTEUS Responsible AI Guideline}},
  type        = {Guideline},
  institution = {Helmholtz-Zentrum Dresden-Rossendorf (HZDR)},
  year        = {2026},
  version     = {0.1},
  doi         = {10.5281/zenodo.XXXXXXX},
  url         = {https://doi.org/10.5281/zenodo.XXXXXXX},
  note        = {Horizon Europe project PROTEUS, Grant Agreement No. 101296397}
}
```

## Other formats

The repository contains a [`CITATION.cff`][repo] file, so GitHub's
**Cite this repository** button and Zenodo both generate citations in
further formats automatically.
