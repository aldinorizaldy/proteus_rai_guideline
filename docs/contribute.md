# Contribute & feedback

This guideline is a living document. Feedback from partners, users and
reviewers is very welcome and is handled openly through GitHub issues.

[Feedback on a section][new-feedback]{ .md-button .md-button--primary }
[Suggest a new item][new-item]{ .md-button }

## How to open an issue

1. Sign in to [GitHub](https://github.com/) (a free account is enough).
2. Go to the [issue tracker][issues] and click **New issue**.
3. Choose a template:
    - **Feedback on a section** – something is unclear, wrong, missing or
      could be improved in an existing section.
    - **Suggest a new item** – propose a new principle, checklist item,
      role, glossary term or reference.
4. Fill in the form and submit. The HZDR RAI team will triage it, label it
   and reply in the issue.

!!! tip "Quick route from any page"
    Every guideline page has an **Edit this page** button (pencil icon,
    top right). It opens the page source on GitHub, where you can propose a
    concrete wording change as a pull request.

## What happens next

Accepted feedback is folded into the master Google Doc and appears on this
site with the next release. Each change is listed in the
[changelog](changelog.md).

## Code of conduct

Please keep discussions respectful and constructive. Do not post personal
data or confidential project information in public issues; contact the RAI
lead at HZDR directly instead.
