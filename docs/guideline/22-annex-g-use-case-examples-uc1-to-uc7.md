# Annex G: Use-Case Examples (UC1 to UC7)

This annex gives EO-specific examples of how the guideline applies to each PROTEUS use case: displacement monitoring (UC1), crop stress (UC2), irrigation (UC3), urban air quality (UC4), wildfires (UC5), flood risk (UC6) and research and education (UC7). For each use case it lists the principles and risks that matter most, the lifecycle requirements that need particular attention, the main evidence expected (for example calibrated uncertainty, per-region performance or geoprivacy screening), and the points where human oversight is required before outputs are used. The examples are kept in this annex so that the core guideline stays applicable to EO applications beyond PROTEUS, and they are updated as the use cases mature and the results of the KR06 evaluation become available.
