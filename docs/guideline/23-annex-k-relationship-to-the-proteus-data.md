# Annex K: Relationship to the PROTEUS Data Management Plan

This annex explains how the guideline and the PROTEUS Data Management Plan (D1.2 and D2.1), led by SERCO, fit together. The Data Management Plan governs how data are collected, stored, shared and documented under FAIR principles. This guideline adds the responsible AI requirements that apply to the same data, such as privacy and geoprivacy screening, coverage and bias documentation, and licence checks. The annex lists the shared metadata fields, states which document is authoritative for each topic, and describes the coordination with WP9 and WP10 so that the responsible AI metadata, which builds on the metadata that partners already produce for FAIR principles and DCAT-AP, is exposed through the catalogues and standard APIs of the platform. It also covers the links to the Consortium Agreement on intellectual property and background IP.
