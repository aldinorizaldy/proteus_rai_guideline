# Changelog

All notable changes to the PROTEUS Responsible AI Guideline are documented in
this file. Versions follow `MAJOR.MINOR`: a new major version for substantive
changes to principles or obligations, a new minor version for clarifications,
additions and editorial fixes.

## [Unreleased]

### Added

- **At a glance** page: a 5-minute summary quoted from the guideline, with a
  source link on every block.
- **Quick tools** for people who build, train or release models, datasets or
  agents: Start here, use-case pages, requirements checklist, risk-tier
  self-check, compliance card and worked example. They are generated from the
  annexes and show "Coming soon" until an annex is filled in.
- Every Guideline page links the official document (Word and PDF).
- "Compliance card submission" issue template.

### Changed

- Replaced the placeholder sections with the working draft from the master
  Google Doc (23 sections, including Annexes A–H).
- Core guideline made generic for AI in Earth observation; PROTEUS-specific
  content moved to new Annexes I–L (project context, automated validation,
  Data Management Plan, roadmap to D2.2).

## [0.1] – 2026-11-02

### Added

- First public website for the guideline, with placeholder sections.
